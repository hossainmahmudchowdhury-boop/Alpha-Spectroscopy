# Alpha-Spectroscopy
In this project this spectroscopy will differnciate the atomic resoulance about liquid substances in different water body .

The purpose of this project is to make Raman spectroscopy more accessible, more reproducible, and more economical. It can be used to non-destructively identify chemicals, polymers, pharmaceuticals, and minerals by analyzing the molecular "fingerprint" of the sample.

The optical design follows a common epi-illumination (backscattering) geometry where the objective lens is used to both illuminate the sample with a laser beam and collect the back-scattered light for detection
